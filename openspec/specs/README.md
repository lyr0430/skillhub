# OpenSpec 系统规格

本目录存放**系统规格（specs）**——即跨变更稳定的平台级契约（领域模型、能力、API 语义）。

## 约定

- 每个规格对应一个稳定的能力/领域（如「技能发布」「审核治理」「身份与坐标」「搜索」）。
- 规格随需求演进**增量更新**，而非推倒重建。
- 当前变更的**需求提案与设计**在 `openspec/changes/<change-id>/`，specs 是长期基线。

## 如何维护

1. 新需求的 proposal/design 里出现对既有能力的新约束时，回写/更新此处对应规格。
2. 规格变更与架构权威文档（`docs/NN-*.md`）保持一致，冲突时以 `docs/` 为准并在规格中标注。
