## 需求摘要

（来自 `proposal.md`）

切片一已实现共享安装：真实文件落盘到 `~/.skillhub/skills/<slug>/`，各 agent 目录下是指向它的软链接。但「本地技能」页扫描逻辑有两个盲区——跳过 `.` 开头目录、且只有 agent 维度没有仓库维度，导致用户看不到共享仓库内容。

本切片（切片二）交付：
1. `.skillhub` 作为展示分类，与 agent 平级（G1，验收 1-3、9-10）。
2. 引用关系展示：一个共享技能被哪些 agent 链接（G2，验收 4-5）。
3. **仓库卸载**：从 `.skillhub` 分类删除技能真实目录 + 所有指向它的链接（验收 6-8）。

**不做**：孤儿技能自动清理 / 批量垃圾回收、批量迁移、`.skillhub` 作为安装目标、线上版本对比 / 更新·替换（切片三）。

## 技术方案摘要

（来自 `design.md`）

- **建模用方案 A**：不新建独立 `RepoEntry` 结构与第二套聚合逻辑，而是把 `~/.skillhub/skills/` 以合成 agent id `.skillhub`（`REPO_AGENT_ID`）加入 `scan_roots` 的输入。现有 `aggregate()` 已按 canonical 真实路径归并，仓库项与 agent 链接自然聚合到同一个 `LocalSkill`。
- **派生字段**：`repo_managed`（locations 含 `.skillhub`）与 `linked_agents`（其余指向它的 agent）在聚合末尾一次性算出，零额外遍历。
- **前端分类**：`.skillhub` → 所有 → 各 agent；`.skillhub` 用仓库图标区分；选中时 `visibleSkills` 过滤 `repoManaged`；`.skillhub` 不进 `AGENT_PROFILES`，天然不可选为安装目标。
- **仓库卸载**：独立命令 `uninstall_repo_skill_command`，不复用 `uninstall_location`（后者 `ensure_under_agent_root` 只认 agent root，会拒掉仓库路径）。顺序**先删所有链接（只删链接），后删真实目录**；`remove_dir_all` 前用 `symlink_metadata` 确认目标是真实目录（非链接）。

## 实现摘要

- 扫描层：`local_skills.rs` 新增 `REPO_AGENT_ID`、`scan_local_skills()` 追加 `repo_root()` 为第六个扫描源、`LocalSkill` 新增 `repo_managed`/`linked_agents` 派生字段、`uninstall_repo_skill` + `UninstallRepoResult`。
- 链接发现：`link.rs` 新增 `find_links_to_target_under()`（返回 `(links, discovery_warnings)`，发现失败不再静默）。
- 命令：`commands.rs` 注册 `uninstall_repo_skill_command`，`lib.rs` 注册到 invoke_handler。
- 前端：`local-skills.tsx` 新增 `.skillhub` 分类按钮、过滤逻辑、仓库卸载确认弹窗；`local-skill-card.tsx` 引用徽章 + 被引用 agent 列表 + 仓库卸载按钮；`tauri-installer.ts` 新增 `uninstallRepoSkill`；`local-skills.test.tsx` 新增 `.skillhub` 测试组。
- i18n：zh/en/ru 三份 locale 新增 repo/ref 相关文案。
- 测试：新增 `repo_display_tests.rs`（Rust）；前端 8+ 个 `.skillhub` 分类测试。
- 文档：回写 `docs/architecture/implicit-contracts.md` §10（合成扫描源、仓库卸载语义、受管唯一定义）；修订父提案非目标。

## 评审结论

（详见 `评审记录.md`）

四位并行评审代理（Rust / TypeScript / 安全 / OpenSpec 对齐）。

**有条件通过**。评审发现的 1 HIGH + 3 MEDIUM + 5 LOW 已全部修复并补回归测试：

| 级别 | 问题 | 处理 |
|---|---|---|
| HIGH | 更新流程回归：`.skillhub` 成 `locations[0]`，共享技能更新被 `ensure_under_agent_root` 拒 | 已修复：`handleUpdate` 优先选真实 agent 位置 |
| MEDIUM | 仓库卸载无条件删除非受管目录，违背 §10 受管唯一定义 | 已修复：按 `has_metadata` 分叉，非受管备份 |
| MEDIUM | 链接发现失败被静默吞掉，可能删目录留悬空链接 | 已修复：返回 discovery_warnings，非空则保留目录 |
| MEDIUM | 部分链接失败分支未测试 | 已修复：补 link-failure 回归测试 |
| MEDIUM | 前端 `busyId` 对仓库操作不生效 | 已修复：`busy` 增加 repo 分支 |
| LOW×5 | refBadge 单数语法、错名测试、重复 import、locale 换行、测试只断言 mock | 已修复 |

评审后用户反馈补充修复：**per-agent 卸载弹窗误列 `.skillhub` 真实目录为可选项**——已修复（`openConfirm`/弹窗过滤 `.skillhub`），补回归测试。
