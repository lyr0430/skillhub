# 评审报告：skillhub-repo-display-20260917-01

> 评审时间：2026-09-17
> 评审方式：并行四位评审代理（Rust / TypeScript / 安全 / OpenSpec 对齐）

## 主评审结果（OpenSpec 对齐）

### 严重问题（必须修复）
1. **[HIGH] 更新流程回归** — `web/src/pages/dashboard/local-skills.tsx:183`。`handleUpdate` 用 `skill.locations[0]`，而 `.skillhub`（0x2E）在 `aggregate()` 的 agent 字典序排序中排在字母之前，成为共享技能的 `locations[0]`。更新时把 `agent: '.skillhub'` + 仓库路径传给 `install_skill`，其 `ensure_under_agent_root` 只认 5 个 agent root，仓库路径被拒（`outside_agent_root`），`should_share_to_repo` 也因 `dir.is_some()` 强制为 false。**共享技能更新失败。**

   **已修复**：`handleUpdate` 改为 `locations.find((c) => c.agent !== REPO_CATEGORY_ID)`，优先选真实 agent 位置（更新经 `resolve_install_target` 写真实目录，任意共享同一目录的 agent 位置等价）。已加回归测试 `updates a shared skill through a real agent, not the .skillhub classifier`。

### 警告问题（建议修复）
1. **[MEDIUM] 仓库卸载无条件删除非受管目录** — `local_skills.rs:430`（`remove_repo_item`）只判 `is_dir()`，未走 `has_metadata`。per-agent 路径（`uninstall_location_under:369`）对非受管目录是备份，仓库路径却直接删，违反隐性契约 §10「「受管」只有一个定义」。手放进去的目录无备份地被删。

   **已修复**：`remove_repo_item` 分支 `has_metadata(real_dir)`——受管 → `remove_dir_all`；非受管 → `backup_dir` 重命名备份。`UninstallRepoResult` 新增 `backup_dir`，前端 `handleRepoUninstall` 报备份详情。已加回归测试 `repo_uninstall_backs_up_an_unmanaged_directory`。
2. **[MEDIUM] 链接发现失败被静默吞掉** — `link.rs` 的 `find_links_to_target_under` 对 `read_dir`/`classify`/`canonicalize` 错误全 `continue`/`unwrap_or(false)`，某 root 读不了时 `remove_repo_item` 会照删真实目录，留下一个没发现的悬空链接。

   **已修复**：`find_links_to_target_under` 改为返回 `(links, discovery_warnings)`，读不了 root / 条目分类失败时上报警告；`remove_repo_item` 把 discovery 警告并入 `warnings`，非空则保留真实目录。
3. **[MEDIUM] 部分链接失败分支未测试** — `remove_repo_item` 的 `ok:false` 保留目录分支无测试。

   **已修复**：新增 `repo_uninstall_keeps_the_directory_when_a_link_fails`（chmod 锁定 agent root 使 `remove_file` 失败，断言保留目录 + 报告 `claude-code` 警告）。
4. **[MEDIUM] 前端 `busyId` 对仓库操作不生效** — `handleRepoUninstall` 设 `busyId=repo:${slug}`，但卡片 `busy` 只匹配 `${agent}:${path}`，卸载进行中按钮仍可点、无反馈。

   **已修复**：`busy` 增加 `busyId === 'repo:${skill.slug}'` 分支。

### 用户反馈补充修复（评审后）
1. **[HIGH] per-agent 卸载弹窗误列 `.skillhub` 真实目录为可选项** — 软链接技能（如 `openclaw` 中的 `@global/zero-slop` 指向 `.skillhub`）在 per-agent 卸载二次确认框里会把 `.skillhub` 仓库真实目录也列出来供选择。语义错误：该目录只能在仓库分类下卸载；若选中会被 `ensure_under_agent_root` 拒绝。
   **已修复**：`openConfirm` 与弹窗均过滤掉 `agent === '.skillhub'`，只列出真实 agent 位置；单真实位置时直接预选、无选择列表。已加回归测试 `does not offer the .skillhub repo as a location in the per-agent uninstall dialog`。

2. **[LOW]** `repo_uninstall_refuses_a_path_outside_the_repo_root` 测试名不符实际（测的是 missing-entry）——已改名 `repo_uninstall_errors_on_a_missing_repo_entry` 并注明无显式 containment 检查（结构性是安全的）。

## 架构评审（Rust 走查）

- **路径遍历**：`validate_slug`（`agents.rs`）拒绝 `/`、`\`、前导 `.`、空串、超长，`repo_root().join(slug)` 恒为单段直接子目录，无逃逸。安全评审确认此为充分边界。
- **`remove_dir_all` 不删穿链接**：`symlink_metadata().is_dir()` 对目录 symlink 为 false（不跟随链接），拒绝把链接交给 `remove_dir_all`。实测确认 std 不跟随嵌套 symlink。
- **链接发现**：仅匹配 `LocationKind::Symlink` + canonical 相等，异源链接 / 悬空链接 / 链接到文件不误命中；agent id 从 `(agent, root)` 元组取，无 zip 错位。
- **`spawn_blocking`**：与既有命令一致，正确移出 async executor。
- 无 CRITICAL/HIGH 遗留。
