### 警告问题（WARNING）
1. **W1（中）— 配置路径失效后用户无法恢复**：外接盘卸载 / 目录被删后，`from.is_dir()` 预检失败，set/reset 双双失败，用户被锁死。
2. **W2（中）— 仓库内 symlink 条目重写链接的破坏性边界**：`create_link` 拒绝 symlink 源，重写循环先删后建会把仍指向外部真实目标的可用链接删掉并重建失败。

### 备注问题（LOW）
- L1：「恢复默认」按钮始终显示（design 要求 ≠ 默认时显示）。
- L2：`getSkillStoragePath` 加载失败未 `.catch`。
- L3：TS `StorageMigrationResult` 含 `ok` 但 Rust `StorageMigration` 无 `ok`（无害）。
- L5：`set`/`reset` 中 `agent_roots` 构造重复（可抽 helper）。
