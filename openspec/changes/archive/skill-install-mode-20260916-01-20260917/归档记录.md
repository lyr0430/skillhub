## 需求摘要

（来自 `proposal.md`）

网页端「安装到 agent」当前只复制安装命令，用户需自行打开目标 agent 粘贴执行，步骤繁琐、无反馈。本变更把「部署到本地」价值承接下来，并引入安装方式偏好：

- **安装方式偏好**：共享安装（真实文件落盘到 `~/.skillhub/skills/<slug>/`，各 agent 目录软链接指向它）或独立副本（每个 agent 各存一份），全局单选开关，默认共享。
- **设置入口**：页面右上角齿轮按钮 + 居中弹窗（Tauri only），Web 端无入口。
- **已有技能添加到其他 agent**：`attach_skill_to_agent`，shared = 链路 / copy = 复制。
- **明确不做**：`.skillhub` 展示分类（切片二）、线上版本对比/更新替换（切片三）、孤儿清理、批量迁移、`.skillhub` 作为安装目标。

## 技术方案摘要

（来自 `design.md`）

- 前端持久化：`install-mode.ts` 读写 localStorage，默认 `shared`；`resolveInstallMode()` 在点击动作时解析而非闭包捕获 hook 值。
- 设置形态：浮层（左菜单 + 右内容），由 `Layout` 在 header 之外渲染（规避 `backdrop-filter` 改变 `fixed` 定位基准的顶栏陷阱）；顶栏内浮层不用 Radix portal。
- Rust 安装分支：`InstallMode` enum，`repo_skill_dir`，shared 模式先落盘仓库目录、后建链接（避免 `swap_into_place` 的 rename 把链接换成真实目录）。
- `attach_skill_to_agent`：源校验用 `is_skill_package`（存在 SKILL.md），非 `ensure_under_agent_root`（源在 agent root 之外）。
- agent 目录映射对齐 `cli/src/agents/profiles/`。
