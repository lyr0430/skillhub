## 主评审结果（OpenSpec 对齐）

### 严重问题（必须修复）
1. **[HIGH-安全] attach 源目录只受「含 SKILL.md」内容检查约束，无位置边界** — `attach.rs:44` `resolve_attach_source`。`source_dir` 来自 webview，仅校验 `canonicalize` + `is_dir` + `is_skill_package`（存在 `SKILL.md`），未限位置。任意含 `SKILL.md` 的目录（如 `~/Documents/MyProject`）都能被 `mode=Shared` 链路或 `mode=Copy` 复制进 agent 根。虽是内容嗅探而非授权边界，但配合 `capabilities` 不生效 + `csp:null`，一处 DOM XSS 即可把任意技能目录扇入 agent 根。
   **已修复**：新增 `skill_source_roots()`（各 agent root + `repo_root()`）与 `assert_skill_source_within_roots()`，在 `attach_skill_to_agent` 入口（真实根）校验源必须落在这些合法技能家之一；纯函数 `resolve_attach_source`/`attach_under` 保持可测（temp tree 源仍接受）。补测试：`skill_source_roots_contains_the_repo_and_every_agent_root`、`rejects_a_source_outside_the_skill_roots`。
2. **[HIGH-依赖] 未注册的 `tauri-plugin-dialog` 运行时依赖** — `Cargo.toml:28` + `package.json:54` 引入，但 `lib.rs` 无 `.plugin(...)` 注册、前端无 import。死 native 依赖，增加构建体积 + CVE 面。
   **已修复**：从 `Cargo.toml` 与 `package.json` 移除，重建 `Cargo.lock` / `pnpm-lock.yaml`。
3. **[HIGH-i18n] 死掉的 `backedUpTo` key 无调用点** — 三份 locale 都有 `skillDetail.installForAgent.backedUpTo`，无任何组件引用。
   **已修复**：三份 locale 移除。
